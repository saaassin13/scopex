# ScopeX

在 NVIDIA DGX Spark 上运行的离线、对话式本机工作助手。

> 当前状态：需求基线已确认。本 README 用于初始化仓库，尚未交付可执行的 POC 验证包，也没有完成 Spark 实测。模型、推理后端和 Agent 运行时尚未定型。

## 项目目标

用户给出目标后，助手在授权范围内自主寻找数据、选择工具、结合项目知识、执行分析与验证，交付有证据的结果。执行过程可见，用户可以打断、纠正，并在保留有效上下文的基础上继续。

优先复用开源、轻量、现成的 Agent 能力，不从零开发通用 Agent，也不把整个业务调查过程写成固定工作流。不预设 OpenCode 或 OpenClaw 胜出；继承已有验证结果，复测必须说明改变量与待验证假设。

## 已确认需求与首版边界

- 硬件固定为现有 Spark；模型、量化、推理服务、运行时均可调整。
- 完整任务链离线运行，包括图片分析、上下文整理和项目知识使用。
- 支持聊天、文件查找与读取、日志分析、图片理解、服务和资源检查；允许授权范围内的临时编程及脚本执行。
- 支持项目说明、业务知识、Skill 和少量专业脚本；模型自主组织调查步骤。
- Web 或终端均可；呈现行动依据摘要、工具动作和进展，支持中断与继续。不依赖展示完整内部推理。
- 常规读取和分析自主完成；修改生产配置、重启服务等操作须确认。中断不等于撤销已执行操作。
- 首版按单用户、一个主要任务验收；复杂诊断分档计时，不承诺所有临时通用任务均达到相同完成率。
- 不承担机器人实时控制；定时巡检、日报和周报暂不作为首轮 POC 的通过条件。

## 验收目标（不是已有成绩）

| 维度 | 目标 |
|---|---|
| 常见简单任务 | 至少 90% 在约 120 秒内自主正确完成 |
| 确定性提取、状态检查 | 自主正确完成率至少 95%；单次提取结果须无漏项、无多项、字段正确 |
| 复杂业务诊断 | 以约 2–5 分钟作为规划预算；按案例和证据单独验收 |
| 交互 | 看得见真实进展；可以中断、纠正、继续；不依赖人工逐步指导 |
| 离线与权限 | 断网后任务链完整可用；未经授权的生产修改阻断交付 |

两分钟内自主正确完成率 = 120 秒内正确交付且未接受人工步骤指导的次数 / 同类任务全部尝试次数。

自动重试计入同一次任务及总耗时；自主完成、人工介入后完成和未完成分别记录。超时停止、生成总结或声称完成不等于成功。模型已加载的任务延迟和冷启动时间分别记录。

## 计划交付物

1. 可直接使用的本机助手及固定版本配置。
2. 首批项目能力包：日志、按时间找文件与读图、Spark 服务与资源检查。
3. 任务产物与证据记录机制。
4. 可复现部署材料、离线依赖清单、更新与回退说明。
5. 测试集、评分规则、执行记录和验收报告。
6. 项目知识、Skill、脚本和权限的维护说明。

## POC 路线

| 阶段 | 要回答的问题 |
|---|---|
| 基线整理 | 保留原先失败的日志、任务要求、正确答案和已知配置；未知项不推断补齐 |
| POC01 基础验证 | 相同任务直接输入、经工具读取、短链路执行和实际读图时，正确性与耗时有什么差异 |
| Agent 执行验证 | 现成运行时能否自主选择动作、有效恢复并正确结束 |
| 项目增强 | 知识、Skill 和脚本是否提高真实业务判断能力，并能处理输入变化 |
| 交互与权限 | 能否真正打断、继续和控制有副作用的操作 |
| 重复与离线验收 | 多次重复、未参与调优的案例、断网重启与业务共存是否通过 |

POC01 的详细 Spark 操作手册、测量脚本、样本、评分和结果模板尚未在本提交中交付。基础探针仅用于分离模型、协议和工具链问题，不替代现成 Agent；探针通过也不代表最终产品指标通过。

## 数据安全

本仓库公开。真实生产日志、图片、模型权重、设备配置、原始请求响应和密钥应保留在 Spark 本机，不提交到此仓库。后续运行材料必须采用本地输出目录及明确的忽略规则；忽略规则不等于自动脱敏。
