## 场景与判定边界

牛全部在转盘上，两个监控视角都看不到整牛：全景（监控1）可见机器人（黄色
外衣）、转盘和转盘上的牛腿/牛屁股等部分；近景（监控2）正对牛腿牛屁股，
为消毒作业视角。异常是牛从转盘上滑落（后腿/屁股先出槽），终态为半悬挂
或完全掉落在转盘外地面；检测掉落以全景视角为准。

因此主判据不能依赖 COCO cow 检测（整牛形态，实测牛屁股近景 cow 零检出）：

- **主识别手段是禁区前景检测**：转盘外走道正常情况下没有任何物体，
  该区域内出现持续前景即异常，不需要识别那是什么；
- **YOLO cow 检测降级为辅助标注**：仅在禁区已被占用时运行，检出 cow
  则事件带 cow 标记；cow 规则（框中心出转盘/越平台线）保留为独立观测；
- VLM 仅作事件触发后的解释与二次确认（密集帧序列）；
- 不做告警推送；事件片段与结论落盘，页面可查。

## 离线回放标定结论（2026-09-26）

用 POC 遗留的 4 段生产录像（camera-96 全景，端侧复制到 workstation
`video-replay/`，共 ~50 分钟）做全速前景扫描（`scripts/scan_foreground.py`）：

| 录像 | 时长 | occupied 帧率 | 最长连续占用 |
|---|---|---|---|
| smoke-30s | 30s | 15% | 1.5s |
| production-10m | 10m | 20% | 2.5s |
| production-20m | 20m | 27% | **4.0s** |
| empty-turntable（无牛空转） | 20m | 29% | **16.0s** |

全部瞬态来自机器人机械臂（空转盘时段臂悬停走道上空可达 15.5s，
前景占比 0.37）；已确认正常段（转盘停止、吸奶器阻挡）无持续占用。
**机器人臂与掉落区在图像上重叠，几何挖除不可行——用时间尺度分离**：

- `trigger_sustain_s = 30`（原 4s）：机器人最长驻留 16s 全部滤除，
  掉落牛在被处理前持续存在，30s 首报（用户确认无硬性时限）；
- 禁区 = 显式多边形 `forbidden_zones`（下方走道，右界避开机器人底座），
  不再使用"转盘外全部"——牛体高出转盘平台、转盘旋转会在上部产生持续前景；
- MOG2 history=300@2fps≈150s：掉落前景约 2.5 分钟后被背景吸收，
  事件取证（前 30s+后 30s）在吸收前完成。

标定产物：`docs/monitoring/zones-camera-96-v1.json`。
风险保留：机器人故障驻留 >30s 会触发事件（宁多勿漏，VLM 确认层兜底解释）。

## 模块结构

```text
monitor/cow_fall/
├── zones.py       区域几何：转盘多边形（射线法）、显式禁区多边形、
│                  框重叠比（栅格采样）、平台线带符号垂距
├── foreground.py  主判据：MOG2 背景建模 ∩ 禁区 mask
│                  → 前景面积比 + 最大连通域质心（去重空间锚点）；
│                  含 warmup 保护（前 50 帧静默学习）
├── rules.py       cow 辅助规则：
│                  R1 完全掉落 = 框中心在转盘多边形外
│                  R2 半悬挂 = 框大部分越出转盘 / 底边越过平台线（含容差）
├── tracker.py     持续状态机 + 去重：
│                  · 异常持续 ≥ trigger_sustain_s（30s，标定值）才触发
│                  · 活跃事件期间同位置观测合并续记，不重复建事件
│                  · 空间分离（> merge_distance_px）的第二事件可独立触发
│                  · 异常消失 ≥ clear_sustain_s（10s）事件关闭
├── detector.py    YOLOv8n ONNX（COCO 预训练，cow=19）CPU 推理；
│                  letterbox + RGB 前处理与 ultralytics 官方逐位对齐
│                  （实测同图同置信度同框）；解码/NMS 可脱离会话测试
├── capture.py     ffmpeg image2pipe 拉流抽帧 + 时间窗环形缓冲；
│                  JPEG 流按 SOI/EOI 切分；read1 逐块读（read(n) 会等满
│                  n 字节，低码率流帧延迟无界）；FileReplayCapture 用
│                  -re 按原生帧率回放文件，时间语义与直播一致
├── session.py     会话编排：前景安静时跳过 YOLO（常态 CPU 极低），
│                  禁区占用才跑 cow 辅助标注；事件触发即快照缓冲
│                  （前 30s + 后 30s 增量落盘）并回调确认方
├── calibrate.py   交互标定：参考帧上点选转盘多边形与平台线，输出 zones JSON
└── __main__.py    会话 CLI；直播凭据从 stdin JSON 读入不落盘；
                   --video 走离线回放（无需凭据，时长自动探测）
```

scripts/scan_foreground.py：离线标定扫描工具（全速解码，输出占用段
run-length 分析），zones 标定迭代用。

## 并发契约

- 采集与检测持续运行，事件处理（快照落盘、VLM 确认）全部异步，不暂停检测；
- 同一异常在分析期间只保留一个活跃事件；事件关闭条件是异常状态消失。

## 部署参数（已标定 v1）

| 参数 | 值 | 依据 |
|---|---|---|
| fps | 2 | 滑落动作 1–2s，0.5s 粒度足够 |
| min_area_ratio | 0.02 | 正常噪声 <0.015，机器人臂峰值 0.37（由时间阈值滤除） |
| warmup_frames | 50 | 启动 25s 盲区，一次性成本 |
| trigger_sustain_s | 30 | 三段录像最长瞬态 16s + 余量 |
| clear_sustain_s | 10 | 异常消失后事件关闭 |
| merge_distance_px | 300 | 同一掉落的空间合并 |
| event_pre/post_s | 30/30 | 取证窗口 |
| buffer_window_s | 300 | 环形缓冲深度 |

相机：端侧 40 网段 camera-96 / camera-98（192.168.40.96/98，端侧可路由）。
RTSP 端口/路径/凭据由使用方提供，凭据不写入仓库。
